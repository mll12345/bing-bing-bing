它是怎么“冰”的

  1. 抽取音轨：mp4 里的 AAC 音轨直接用 WebAudio decodeAudioData 解出 PCM（失败回退录流解码）。
  2. 分离人声：立体声里人声几乎总在正中、伴奏偏两侧；逐帧逐频点算「中置占比」做软掩蔽，把人声从伴奏里拆出来。
  3. 跟踪旋律：FFT 自相关逐帧测基频（10ms 步长），音量骤降 / 音高跳变处断字 —— 于是一个音符 = 一个字 = 一个「冰」。
  4. 合成冰声：每个字现场共振峰合成一个 /piŋ/ 音节（/p/ 爆破 + /i/ 元音 + /ŋ/ 鼻音尾），基频锁在原歌词的音高上，所以旋律还是那首歌的旋律。
  5. 去掉原唱：默认把分离出的人声完全替换成冰声，只留伴奏（「原唱残留」可调回）。
  6. 可选加料：冰裂咔嚓、冰洞混响 —— 默认很轻。没有变速、没有升调、没有四四拍鼓机，听感就是原曲。
  7. 母带：高通 → 空气感 EQ → 软削波 → 轻压缩 → 限幅，峰值收到 0.955。
